# 装箱台 PackDesk

> 和开源项目 **PackingProof** 没有关系。本项目只是能把录像**备份到** PackingProof 电脑端，
> 后续会有自己的电脑端（同名 PackDesk）。

手机浏览器里跑的打包出库留证工具：**扫快递面单自动录像 → 录像中扫商品码提纯序列号并抓拍 → 按单号归档**。
纯前端单页 PWA，数据只存在手机本地（IndexedDB），不上传任何服务器。

👉 网页版 **https://qiukun39.github.io/qr-collector/**
📱 安卓 App **[packdesk-3.7.apk](packdesk-3.7.apk)**（[直接下载](https://qiukun39.github.io/qr-collector/packdesk-3.7.apk)）

两者**代码同一份**。App 版多了：系统原生语音播报（不受麦克风占用影响）、
安装时一次性授权、必然生效的屏幕常亮、无地址栏、资源直接打进包。
构建方式见 [app/README.md](app/README.md)。

## 工作流

```
扫面单条码 ──→ 自动开录（屏幕常亮）
                  ↓
           录像中随时扫商品码
                  ↓
    每扫一个：提纯序列号 + 抓拍一张带水印的照片 + 计入本单
                  ↓
   扫控制卡 / 扫下一单 / 手动按钮 ──→ 停录保存
                  ↓
        快递单号 ┬ 一段录像
                ├ N 个序列号（多列）
                └ N 张照片
```

## 三种业务类型

| 类型 | 入口 | 录像 | 容器 | 用途 |
|---|---|---|---|---|
| 发货 | 打包发货录像 | ✅ | 快递单号（扫面单自动开） | 装箱台 |
| 退货 | 拆包退货录像 | ✅ | 快递单号 | 拆包留证 |
| **盘点** | **扫码盘点** | ❌ | **任务名（手输）** | **到货验收、盘库存** |

三者共用同一套存储、搜索、CSV 导出、字段规则与备份，首页按类型筛选。

### 扫码盘点（不录像）

到货验收和盘库存不需要视频，录了纯占空间。这个模式：

- 点中间大按钮 → 填任务名 → **每次单独选本次拍不拍照**（盘点几百件时建议关）
- **盘点识别规则**（防止微信码、网址码被当成商品记进去）：

  | 档位 | 判定 |
  |---|---|
  | 仅能提取字段的码（默认） | 只记录能被「提取字段」命中的码，最准 |
  | 任意二维码 | QR / DataMatrix / PDF417 等 |
  | 自定义 | 码型 + 长度范围 + 必须前缀 + 过滤前缀 |
  | 任意码 | 什么都记，容易混入无关二维码 |

  被忽略时会提示原因，排查「为什么没反应」。常驻输入框走同一套规则。
- 大字实时显示刚扫到的序列号和序号，远距离也看得清
- **重复扫到同一件：红屏闪烁 + 长震 + 语音「重复扫描」+ 不计数**——盘点最怕重复计数
- 底部有**常驻输入框**，蓝牙扫码枪当键盘打进来回车即入库，比举手机对焦快得多
- 控制卡照常可用：`[CMD:STOP]` 结束任务，`[CMD:SNAP]` 需要留证时拍一张

## 扫码控制卡（全程零触屏）

打包员戴手套作业，封箱后不用腾手点屏幕——把控制卡往镜头前一晃即可。
设置页「控制卡 / 打印」可生成 A4 可打印的卡片，剪下塑封。

| 卡片 | 作用 |
|---|---|
| `[CMD:STOP]` | 停止并保存当前单 |
| `[CMD:SNAP]` | 抓拍，用设置里的倒计时 |
| `[CMD:SNAP0]` `[CMD:SNAP3]` `[CMD:SNAP5]` | 抓拍，固定 0 / 3 / 5 秒倒计时 |
| `[CMD:PAUSE]` `[CMD:RESUME]` | 暂停 / 继续 |
| `[CMD:DROP]` | 丢弃本段重录（旧卡 `[CMD:DISCARD]` 仍兼容）|

抓拍倒计时期间屏幕显示大字倒数、每秒「嘀」一声，到点「咔嚓」+ 白闪，
给打包员时间把东西摆到镜头下。

同一张卡**必须离开画面后才会再次触发**（边沿触发，不是冷却时间），举着不动不会重复执行。

## 水印

两套都有，可分别开关：

- **实时烧录**：录制时直接烧进画面。1080p 吃 CPU，内置掉帧检测——
  连续 2 秒低于 15fps 自动关闭并提示，不会让你录出一堆卡顿视频
- **事后补烧**：单据详情点「补烧水印并导出」，把单号、时间和**本单序列号清单**烧进画面重新导出。
  耗时与视频等长（重编码一遍），适合出纠纷时单独处理某一单

水印样式支持「白字黑描边」和「黑底白字」。

## 码的分类（避免商品条码误触发录像）

同一路摄像头流里同时认三种码，按下面的顺序判定：

1. 文本匹配 `^\[CMD:xxx\]$` → **控制卡**
2. 能被「提取字段」任一规则提纯出内容 → **商品码**（永远优先，不会被当单号）
3. 通过当前**扫码规则** → **快递单号**，开始录像
4. 都不符合 → **直接忽略**（可开提示，排查用）

扫码规则四档：

| 档位 | 判定 |
|---|---|
| 中国大陆快递面单（默认） | 只认 **Code-128/39/93**，12~18 位；二维码、EAN/UPC 商品码全部过滤 |
| 国际一维码 | 任意一维码，8~40 位（S10/UPS/FedEx/DHL） |
| 国际二维码 | QR/PDF417/DataMatrix 面单，6~64 位 |
| 自定义 | 码型（一维/二维/不限）+ 长度范围 + 必须前缀 + 过滤前缀 |

> **ZXing 的两个坑**（都会导致扫不出，已处理）：
> 1. `getBarcodeFormat()` 返回的是**数字枚举**（`CODE_128 = 4`），要先转成名称才能按码型过滤
> 2. 不开 `TRY_HARDER`，一维码只扫画面中间附近几行，面单放画面上下就识别不到；
>    而 `decode(bmp)` 内部会 `setHints(undefined)` 把之前设的 hints 清掉，
>    **必须每次 `decode(bmp, hints)` 传进去**

## 语音播报

开始录像（可带单号逐字读）、重复单号拦截、重复扫描商品、每件计数、
抓拍倒计时报数、拍照完成、停止保存、暂停继续，都有语音。
用系统的 `speechSynthesis`，安卓需装「Google 文字转语音」才有中文声音，设置页会提示是否可用。

## 提取字段（一码多列）

每条规则 = CSV 的一列，**列名相同的多条规则算同一列的备选**，自上而下先命中的生效（用来写兜底）。
★ 标记的列为主值，用于去重、大字显示和照片命名。

默认针对 GS1 DataMatrix（`<GS>` 是 ASCII `0x1D` 分隔符）：

```
<GS>241123-456-789<GS>211AB2345678<GS>250C1DE2345678
     AI 241            AI 21           AI 250
```

| 列名 | 正则 | 输出 |
|---|---|---|
| 客户零件号 | `(?:^\|\x1d\|<GS>)241([0-9A-Za-z-]+)` | `$1` |
| 序列号 ★ | `(?:^\|\x1d\|<GS>)21([0-9A-Za-z-]+)` | `$1` |
| 二级序列号 | `(?:^\|\x1d\|<GS>)250([0-9A-Za-z-]+)` | `$1` |

同时兼容真正的 `0x1D` 控制符和显示成 `<GS>` 的文本。
页面和 CSV 里所有不可见控制符统一显示成 `<GS>` / `<RS>` / `<0xNN>`，避免 Excel 乱码。

## 其它

- **重复单号规则**：提示并禁止录制 / 提示但继续 / 不提示
- **最大录像时长**：到点自动停止保存，防止忘关录成巨型文件
- **视频保留天数**：到期自动清理视频，单据和照片保留
- **取景框与扫描区域**：可设「整个画面」或「仅取景框内」。限定取景框时只解码框内区域，
  避免误扫到画面里别的码；取景框可单独显示/隐藏
- **导出**：APK 内弹出「保存到手机」/「分享 / 发送」（CSV、JSON 再多一项「复制内容」）。
  保存走系统 MediaStore——视频和照片进**系统相册的「装箱台」分组**，文档进
  **「下载 / 装箱台」**，文件管理器能直接找到；网页版走浏览器下载并提示在「下载」文件夹

  > 为什么不写 `Android/data/<包名>/`：安卓 11 起那个目录第三方文件管理器看不到，
  > 导出的东西等于「存了但找不到」。所以一律走 MediaStore。

- **详情页「一键保存全部」**：发货单一次把视频 + 照片 + 清单 CSV 全存出去；
  盘点照片多，会多问一句「打包成一个 ZIP」还是「逐张进相册」

  > ⚠️ **文件名必须纯 ASCII**。安卓 `MimeTypeMap.getFileExtensionFromUrl` 内部用
  > `[a-zA-Z_0-9.\-()%]+` 校验文件名，含中文时取不到扩展名 → MIME 为 null →
  > `intent.setType(null)` → **分享面板空白，看起来就是「无法分享」**。
  > 所有导出文件名都经 `asciiName()` 处理，连目录名也用 ASCII。
- 存储占用实时显示，启动时申请 `navigator.storage.persist()`
- 导出 CSV（按当前筛选和搜索结果导出）、导出单段视频、导出备份 JSON（不含视频）
- PWA，可「添加到主屏幕」，离线可用

## 已知限制

- **必须 HTTPS** 才能调摄像头，`file://` 和局域网 `http://` 都不行
- 页面切到后台时系统可能暂停录像，打包时别切走
- 备份 JSON 不含视频（太大），视频需要单独导出
- 浏览器清理「网站数据」会清掉全部内容，没有云端副本

## 依赖

两个库都**放在仓库 `vendor/` 里自己托管**，同源加载，不依赖 CDN（国内 jsDelivr 不稳），
Service Worker 会预缓存，离线也能用；本地加载失败才回退到 jsDelivr。

| 文件 | 用途 | 何时加载 |
|---|---|---|
| `vendor/zxing.min.js` | 条码解码兜底 | 浏览器没有原生 `BarcodeDetector` 时 |
| `vendor/qrcode.js` | 生成控制卡二维码 | 打开控制卡页时 |

控制卡二维码留 **4 格静默区**（QR 规范要求），实测 160–400px 全尺寸段都能稳定解码。
