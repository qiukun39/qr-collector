# 扫码提纯记录器 (qr-collector)

手机浏览器里跑的扫码工具：扫商品码 → **正则提纯成多列** → **自动抓拍存档** → 本地记录 → 复制 / 导出 CSV·ZIP。
纯前端单页，数据只存在手机本地（IndexedDB），不上传任何服务器。

👉 **https://qiukun39.github.io/qr-collector/**

## 功能

**扫码**
- 摄像头连扫，优先用 Chrome 原生 `BarcodeDetector`，不支持时自动回落 ZXing
- 手电筒、前后摄切换、提示音/震动、扫中自动复制、同码 2.5 秒内不重复触发
- 手动粘贴录入，一次多行

**提纯：一码提多列**
- 每条规则 = CSV 的一列，自己写正则 + 输出模板（`$0` `$1` `${name}`）
- **列名相同的多条规则算同一列的备选**，自上而下先命中的生效（用来写兜底）
- 其中一列标 ★ 为主值，用于去重、大字显示和照片命名
- 规则面板带实时测试框，正则写错直接报语法错误
- 改完规则可**重算全部历史记录**（原始内容和照片始终保留）

**拍照**
- 解码成功那一瞬间自动抓一张，零操作
- 可选在右下角烧录水印（主值 + 时间），照片单独发出去也说得清来历
- 长边 1024/1600/2048 可选，JPEG q0.82
- 文件名模板：`{日期} {时间} {值} {原始} {序号} {列名}`，默认 `{日期}-{时间}_{值}.jpg`
- 列表缩略图，点开看大图，可单张保存

**导出与备份**
- 复制主值（一行一个）/ 导出 CSV / 导出 ZIP（照片 + 索引 CSV）
- **完整备份 ZIP**：`backup.json`（记录+字段+设置）+ `记录.csv` + 全部照片，可完整还原
- 恢复时可选合并（按主值去重）或清空重建
- 距上次备份满 N 条自动提醒
- 搜索框过滤后再导出，只导出筛出来的

**存储**
- IndexedDB，容量与已用空间实时显示
- 启动时申请 `navigator.storage.persist()`，降低被系统回收的概率
- 「只删照片保留记录」一键腾空间
- 自动迁移 v1 的 localStorage 旧记录

**PWA**：可「添加到主屏幕」，离线可用。

## 默认字段：GS1 DataMatrix

商品码形如（`<GS>` 是 ASCII `0x1D` 分隔符）：

```
<GS>241123-456-789<GS>211AB2345678<GS>250C1DE2345678
     AI 241            AI 21           AI 250
```

| 列名 | 正则 | 输出 | 结果 |
|---|---|---|---|
| 客户零件号 | `(?:^\|\x1d\|<GS>)241([0-9A-Za-z-]+)` | `$1` | `123-456-789` |
| 序列号 ★ | `(?:^\|\x1d\|<GS>)21([0-9A-Za-z-]+)` | `$1` | `1AB2345678` |
| 二级序列号 | `(?:^\|\x1d\|<GS>)250([0-9A-Za-z-]+)` | `$1` | `C1DE2345678` |

三个 AI 互不冲突：`241`/`21`/`250` 在分隔符后的前两位分别是 `24`/`21`/`25`。
同时兼容真正的 `0x1D` 控制符和显示成 `<GS>` 的文本。

页面和 CSV 里所有不可见控制符统一显示成 `<GS>` / `<RS>` / `<0xNN>`，避免 Excel 乱码。

## 本地预览

```bash
python3 -m http.server 8000 --bind 127.0.0.1
```

手机上**必须 HTTPS 才能调摄像头**（`file://` 和局域网 `http://` 都不行），所以线上跑在 GitHub Pages。

## 部署

推到 `main` 即自动发布。**改版记得 bump `sw.js` 里的 `VER`**，否则 Service Worker 会继续吃旧缓存。

## 文件

- `index.html` — 全部功能（单文件）
- `sw.js` — 离线缓存
- `manifest.webmanifest` / `icon.svg` — PWA 安装

外部依赖只有两个按需加载的 CDN 脚本：ZXing（原生解码不可用时）、JSZip（打包时）。
